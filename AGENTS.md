# Project Instructions

## Context Management & Project Continuity

You must maintain project knowledge independently
of the conversation history.

1. Read PROJECT_CONTEXT.md and TASKS.md before
   starting significant implementation work.

2. Update TASKS.md whenever a major task is
   completed or implementation status changes.

3. Record important architecture and technical
   decisions in DECISIONS.md.

4. Before context compaction, ensure that:
   - Current progress is documented.
   - Pending tasks are listed.
   - Important implementation details are saved.
   - Known issues and blockers are recorded.

5. After compaction, refer to these files before
   continuing implementation.

6. Never assume an unfinished task is completed.

7. Keep documentation concise, accurate and updated.
